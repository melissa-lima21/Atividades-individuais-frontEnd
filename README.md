## 🚀 Sobre o Projeto

Este repositório contém a resolução da Avaliação Individual da disciplina de Front-End Essencial. O objetivo do trabalho é aplicar conceitos fundamentais de **HTML** e **CSS**, incluindo estruturação de páginas, estilização básica e layouts modernos com **Flexbox**.

## 📂 Estrutura do Repositório

Conforme solicitado nos requisitos da avaliação, o projeto está organizado da seguinte forma:

-   **`exercicio-01/`**: Página de apresentação pessoal.
    
    -   `index.html`: Estrutura da apresentação.
        
    -   `style.css`: Estilização (cores, margens e dimensões).
        
-   **`exercicio-02/`**: Card de produto para loja virtual.
    
    -   `index.html`: Estrutura do card.
        
    -   `style.css`: Estilização do componente.
        
-   **`exercicio-03/`**: Reprodução de layout com Flexbox.
    
    -   `index.html`: Estrutura do layout.
        
    -   `style.css`: Implementação do Flexbox.
        

----------

## 📝 Descrição dos Exercícios

### Exercício 01: Apresentação Pessoal

Criação de uma página contendo:

-   Título principal com meu nome.
    
-   Parágrafo biográfico e lista de 3 hobbies/interesses.
    
-   Imagem representativa com largura definida via CSS.
    
-   Link para rede social ou GitHub.
    
-   Estilização com cores de fundo, cores de texto distintas e uso de `margin`/`padding`.
    

### Exercício 02: Card de Produto

Desenvolvimento de um componente de interface para e-commerce incluindo:

-   Imagem do produto.
    
-   Nome em destaque e descrição curta.
    
-   Preço e botão "Comprar".
    

### Exercício 03: Layout Flexbox

Reprodução técnica de um layout específico utilizando as propriedades de **Flexbox** para garantir o posicionamento correto dos elementos conforme o modelo fornecido.
